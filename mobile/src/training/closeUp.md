# Local close-up analysis

Phase 8D uses TrainingCloseUp in the existing TrainingPose Expo module. AVFoundation samples the imported local file at 10 Hz, applies its preferred display transform once, and reports actual presentation timestamps. Apple Vision hand pose supplies up to two hands with 21 possible joints; object tracking follows only the user-selected rectangle. No semantic recognition, cloud inference, permissions, physical calibration, coaching or scoring is added.

Select a representative frame using the existing player, press Analyze Close-up, drag a region, set pre/post windows, and run. Tracking proceeds forward from that frame, within the first 60 seconds. Select early enough to include the desired pre-event baseline. Lost tracking is terminal for that run: reselect a visible frame/region to start again. Object orientation is omitted because an axis-aligned tracker box cannot establish it reliably.

All coordinates are normalized displayed image space with top-left origin. Velocity is normalized displacement per second; direction is image-plane radians, not a physical angle. Paths never connect across missing samples. Coverage measures contiguous tracked time divided by requested time. Pre-event variance is the sum of X/Y position variances around their means. The pre-event reference is the mean of sufficiently covered, recent samples. Post-event analysis stops at the first tracking break and reports observed initial vector, peak displacement/time, compact return path and observed residual. A settle requires departure followed by 400 ms near a quiet pre-event reference; an offset resting location does not settle. Camera uncertainty suppresses settle results.

Hand identities use unique nearby wrist correspondence. Crossings, missing wrists and long gaps end identity continuity. Proximity means an observed approach followed by 300 ms near the region; it does not prove contact. Transition candidates require sustained efficient displacement across most samples in a 400 ms window; they do not establish intent. Suggestions use CUSTOM with OBJECT_TRANSITION or HAND_OBJECT_PROXIMITY notes and VISION_DETECTED provenance, initially unconfirmed. Existing confirmation/edit/reject controls and observation gating apply. These generic measurements do not contribute physical performance scores.

Whole-image translational registration estimates camera ambiguity. Foreground-dominated scenes can trigger false warnings; rotation, zoom, parallax and drift are not solved. Missing registration lowers confidence. Substantial global movement lowers it further. No camera compensation or high-confidence object-motion claim is made. Low light and blur are not classified separately; they may cause missing joints or tracking confidence loss. Confident tracker drift remains possible and requires visual review.

Persistence uses existing Training JSON/SQLite: fixed detector/config versions, selection, windows, up to 600 compact object samples, 120 hand previews, 160 event summaries/suggestions, 40 points per return path and 20 warnings. No frames are persisted. Validation reconstructs allowed fields and recomputes metrics from paths. Existing-event edits refresh windows; deletion removes stale metrics. Add new markers and rerun to include them. Reruns replace only unconfirmed vision suggestions; all manual and confirmed evidence survives. Other detector runs survive close-up work and vice versa.

Overlay is sparse and time-local, with joints, region, recent center trail, sample confidence/loss and active pre/post window labels. Preview-next-sample seeks precisely to stored timestamps. Missing preview samples are not interpolated. Native fullscreen does not include custom overlays. Region selection temporarily captures drag input; ordinary seeking exits selection.

## Native verification required

Build/autolink TrainingCloseUp on macOS/Xcode, then test on a physical iPhone: Vision API compilation, two hands/crossings, rotated/mirrored/VFR footage, letterbox selection alignment and seek accuracy, tracking loss/leaving frame, low light/blur, foreground-dominated/global-motion footage, cancellation/unmount, unsupported media, save/reopen and confirmed-marker reruns. Windows TypeScript and synthetic tests do not verify these native behaviors.

References inspected: [Expo 57](https://docs.expo.dev/versions/v57.0.0/), [hand pose](https://developer.apple.com/documentation/vision/vndetecthumanhandposerequest), [region tracker](https://developer.apple.com/documentation/vision/vntrackobjectrequest), [global registration](https://developer.apple.com/documentation/vision/vntranslationalimageregistrationrequest).
