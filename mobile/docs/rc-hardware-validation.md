# RC hardware validation — October 15, 2026

This is the single current checklist. All boxes are **unperformed**. It supersedes September 9–10 appointments and older scattered device lists; none were closed by automated tests. Record device model, iOS, build number, text size and outcome. Use a small iPhone and an older supported device where available. Preserve a copy of existing data before upgrade testing.

- [ ] Build/sign the production EAS archive; confirm local Swift modules compile and register, privacy manifests/permissions and icons are valid, minimum iOS is correct, and TestFlight installs. Verify Apple credentials, App Store Connect record, privacy declarations and incremented build number. Also test upgrade over an existing installation without deleting SQLite.
- [ ] Fresh launch, navigation, rapid/repeated Save, leaving while saving, background/foreground and force-close/relaunch: no crash, duplicate writes or stranded modal. Saved matches/stages, duplicate/delete behavior, document references, training sessions and profile remain readable. Unsaved editor edits/undo history are session-local.
- [ ] Persist a mixed straight/rounded route with bends, waypoint reorder, section/waypoint engagement anchors, target assignments and lettering. Save, navigate, undo/redo then Save, force-close/reopen; compare PATH/ENGAGE/REVIEW and coverage. Import acceptance must add objects without changing existing objects or manual route references.
- [ ] Crowded waypoints/bends/arrows/targets: select through canvas and contextual lists in every mode; drag bends at multiple zooms, create engagements on curves, release off-canvas/invalid targets. Add a second finger, pinch, lift either finger, pan, release, interrupt/background; no unintended drag, engagement or locked toolbar. Assess dense-layout snapping/jitter.
- [ ] Small portrait layout: target inspectors, bottom sheets, Fit, safe areas/home indicator, scrolling with keyboard, largest Dynamic Type, VoiceOver labels/actions/focus return and Reduce Motion. Dismiss panels without losing edits. Check paper/steel presets, ports/partial targets, duplicate/delete, 2.5D view and loadout presentation (unfinished September 9–10 checks).
- [ ] Native PDF/image picker: multipage/rotated/image-only PDFs; locked, malformed, oversized and missing files; invalid page and low-storage failure. Originals survive failures/reopening. Camera: deny permission, cancel, repeated capture, no-camera and background interruption; no unexpected microphone/library prompt.
- [ ] Paper corners, perspective correction, rotation/crop landmarks and calibration against known dimensions. Isometric/perspective diagrams stay reference-only. Manual add/type/preset/position/rotation/size, accept/reject, batch decisions, repeat acceptance and bounds/duplicate-start rejection remain usable. Check source/metadata after match/stage duplication and deletion.
- [ ] EXPERIMENTAL detection: unsupported/dense/blank diagrams and cancellation leave manual overlays editable; close/background/reopen cannot apply stale results. Check native RGBA orientation/alpha, all rotations, memory, responsiveness and cancellation latency on large inputs. No real-world recognition claim until actual exports/printout photos are evaluated; no additional recognition development is part of this RC.
- [ ] Existing native training: Files/iCloud MOV/MP4 import, durable copies, playback/seek/step and rotated/mirrored/VFR media; missing/corrupt codec relink and low-storage recovery. Audio with no/late/invalid track; pose with no/multiple/occluded people; close-up boxes at letterboxed edges, tracking loss/camera motion; timestamps and first-60-second limits. Rapid start/cancel/retry/background must not overlap decoders or apply stale output.
- [ ] Existing analysis/profile: evidence edits, reruns, fusion, saved plan mapping/accept/reject, historical geometry, stale suggestion invalidation, profile contribution/rebuild/withdrawal and persistence. Failed writes leave no partial update; healthy rows remain usable beside damaged records. Optional route-assistant unavailable/unsupported states retain manual editing.

Release gate: a successful JavaScript export does not replace the signed native build and the persistence/lifecycle smoke checks above. Physical memory pressure, UIKit layout, gesture latency, AVFoundation/Vision and VoiceOver are unverified. The September checks are over one month overdue and remain open here.
