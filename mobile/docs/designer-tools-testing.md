# Stage Designer tools: phone verification

No physical-device test has been performed by Codex. Run this checklist in the existing native development build. From mobile, run npx.cmd expo start --dev-client; open the app through its development-client QR/link on the phone. These changes require no additional native module or permission.

1. Open Stage Planner > Matches. Create a USPSA match using name/family only. Add a stage using name only. Confirm Stage Settings still edits boundary width/depth in yards.
2. Tap Add Target. Confirm USPSA defaults, with Metric, Classic, Reduced, round plate and mini popper choices. Select Metric. Tap three separate empty stage points. Confirm three additions and that placement remains active. Drag to pan, pinch, lift one finger and pan again; none should add a target. Tap Fit and Done; neither should place anything.
3. Undo once: only the latest target disappears, with no viewport reversal. Redo restores it. Select Pan and drag over a target: only the viewport moves. Select / Move, drag the target, Undo once, then Redo: the entire drag is one action.
4. Add Target > PCSL > Mini Practical. Place it next to full-size Practical. Compare both axes: mini is half the full target dimensions at equal zoom. Zoom in/out; proportions remain correct. Try selecting a small plate through its larger invisible touch area. Inspect saved width/height in yards, with decimals retained.
5. Select a target. Drag the cyan wheel knob clockwise and counterclockwise across north; verify a smooth 359/0 crossing and a stationary anchor. Edit > Rotation (degrees): apply 359, -1 and 721.125; expect normalized values (359, 359 and 1.125). Undo/redo numeric and wheel changes. Confirm a wheel drag is one undo action.
6. Select Draw Wall (swipe the tool row if needed). Press a start point, move while holding to preview length/angle, and release to commit. Tap the next endpoint to add a connected segment. Alternatively tap the initial start, then press/move at the second point. Confirm the preview follows before release.
7. While drawing, test nearly horizontal, vertical and 45-degree segments. Move near an existing endpoint: Endpoint should win over Angle, which wins over Grid. Toggle Snap OFF: fractions and arbitrary angles remain free. Snap grid comes from View > Grid / Snap Settings (existing default is 6 inches = 0.167 yd).
8. Undo last segment removes only the most recently drawn segment and restores its start anchor. Cancel current segment drops only the preview, retaining committed segments. Done exits drawing. Start another preview and switch to Pan/Add Target; no unfinished segment should be saved. Pinch during a preview: cancel preview without committing.
9. Draw Fault Line with two connected segments. Confirm these are distinct ground markings, not solid walls, including in View > 2.5D. Return to Top Down.
10. Select a wall/fault line. Drag each cyan endpoint; opposite endpoint stays fixed, length/angle update. Undo once restores the full drag. Edit length alone, angle alone, then both; the start endpoint remains fixed. Enter zero, NaN or infinity: reject without changes. Shortening a wall below its firing-port width must also reject. Delete a segment and undo/redo it.
11. Save. Back > Matches > Match settings: change USPSA to IDPA. Reopen the original stage. Existing target types, dimensions, rotations and IDs remain unchanged. Add Target now defaults to IDPA; confirm Standard, Alternate, round and square choices. Also test a PCSL match default.
12. Save, close and relaunch the app. Reopen and verify targets, outlines, rotations, walls, fault lines and exact inspector values. Test duplicate stage/match; originals and copies retain geometry. Undo history is session-only and starts empty after reopen.
13. Shrink the boundary around existing targets/segments; cancel once, then keep once. Objects remain available for correction. Save/reopen the smaller boundary. Return to the pre-existing route/loadout screens and verify assignments remain; undoing object deletion restores its associated planning data.

Automated regression coverage is in tests/designer-tools.test.cjs. Optional browser touch check: Expo on localhost:8087, isolated Chromium with debugging on 9228, then node tests/designer-browser-smoke.cjs. This is browser emulation, not native-device validation.
